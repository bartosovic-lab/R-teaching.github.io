# Day 1 · Interactive tutorial: *From a table to a biological story*

[← Back to KN7001](KN7001.md)

**What is this?** A four-hour, hands-on introduction to statistics in R for
students who have never used R. You work in pairs through eight short missions:
first commands, importing a table, describing and plotting data, checking
assumptions, comparing two groups, correcting for multiple tests and reading a
correlation. Every code window comes filled in; you run it, change one thing and
explain the result. Quizzes and short written reflections along the way are
practice, not marks. Using an LLM for hints and explanations is allowed, as long
as you can explain everything you keep.

## Before the workshop

Install [R](https://cran.r-project.org) and then
[RStudio Desktop](https://posit.co/download/rstudio-desktop/). Both are free.
Then **[⬇ download the Day 1 materials (zip, < 1 MB)](../Notebooks/Statistics_lab_2026.zip)**,
unzip it, and keep the folder `Statistics_lab_2026` together.

## Launch the tutorial

Double-click `Statistics_lab.Rproj` in the unzipped folder. RStudio opens,
installs the few packages it needs (first time only, one or two minutes), and
starts the tutorial in a window. Use **Show in new window** for full size. To
stop it, click the red Stop button above the Console.

If it does not start by itself: in RStudio open `day1.Rmd` and click
**Run Document** at the top of the editor.

Everything you type is remembered by your browser. At the end of the tutorial,
type your name and click **Download my work** to save all your code and answers
as one HTML file.

[Read-only preview of the tutorial](../Notebooks/Statistics_lab_2026/day1_preview.html) (all code, outputs and quiz answers; no live code windows)

## What is in the download

The zip unpacks to one folder, `Statistics_lab_2026`:

| File | What it is |
|---|---|
| `Statistics_lab.Rproj` | The RStudio project. Double-click this to start |
| `day1.Rmd` | The interactive tutorial |
| `helpers.R`, `setup.R`, `.Rprofile` | Support code; `setup.R` installs the packages, `.Rprofile` starts the tutorial when the project opens |
| `data/mmse_small.csv`, `data/neurites.csv` | The teaching data (with `data/README.md`) |
| `Launch_day1.command`, `Launch_day1.bat` | Optional launchers that run the tutorial without opening RStudio. On a Mac, a downloaded script is blocked by Gatekeeper: after the first attempt go to System Settings → Privacy & Security and click **Open Anyway**, or simply use the `.Rproj` route above |
| `README.md` | These instructions |
