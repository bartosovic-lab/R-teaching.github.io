Welcome: you are the analysis team

GABA is a signalling molecule whose electrical effect depends partly on chloride regulation. Researchers recorded neurons in the ventral tegmental area of rats during reward learning. The GABA reversal potential is the voltage at which the measured GABA current changes direction. A less negative value is a shift towards more positive voltage; you do not need prior electrophysiology to compare these measurements.

Your question: Does the GABA reversal potential differ between baseline and the acquisition phase of reward learning?

No previous R or statistics is needed. First we will learn to run a command, then follow the measurements into a figure. You are allowed to be surprised by the data. A result that does not support your prediction is still a result worth explaining.

Work in pairs. One person types and the other predicts or explains; swap after each section. Keep your own written answers. Allow 70 minutes for basics, a break, 35 for plots and 5 for the handoff.

Keep several measurements together: c()

c() combines values into a vector, an ordered collection. A function is a named operation; its inputs go inside parentheses. In c(2, 4, 6), commas separate three values. Nothing is being added yet! Run the example. Then append counts <- c(2, 4, 6, 8) and counts to keep and display four values.

2. Meet the data — 10 minutes

One row is one rat, summarised by the mean of its recorded cells. Baseline and acquisition use different rats, not the same rat measured twice. All core animals received the cue followed by reward protocol. In the original paper this protocol is called paired conditioning; that name does not mean our statistical samples are paired.

Our prepared table has 13 animals: 7 Baseline and 6 Acquisition. The original measurements are real, openly available research data. The preparation and exact source are in data/dictionary.html. Dataset · Original study.

Column Meaning
sample_id Animal identifier; a label, not a measured quantity
group Baseline or Acquisition
reversal_mV Mean GABA reversal potential (mV)
resting_mV Mean resting membrane potential (mV), from the same animal

reversal_mV is the GABA reversal potential; resting_mV is the resting membrane potential. The suffix _mV means millivolts. Each value is the mean of the recorded cells from one rat.

A table in R is called a data frame. A row holds information about one animal; a column holds one variable. A nominal category names groups with no ranking; an ordinal category has an order but need not have equal gaps. A continuous measurement can take intermediate values even if the instrument rounds them. Biological meaning matters, not just whether R stores digits. A day number and a named learning phase are different descriptions.

Open the table

read.csv() reads a comma-separated table. Quotes mark literal text, including a file path. <- stores the table as study. head() previews rows, names() lists columns, and dim() reports rows then columns. Run the supplied import, then append head(study), names(study) and dim(study) in that order.

study <- read.csv("data/study.csv")

4. Typical values, variation and an awkward reading — 20 minutes

The mean gives each observation equal weight. The median is the middle of the ordered observations (the mean of the two middle ones when there is an even number). The sample standard deviation (SD) describes variation among observations, in the same units as the measurement. A larger SD means more variation; it does not by itself tell us how uncertain the mean is. Sample size also matters for that.

Which group varies more?

Run the supplied mean and median calculations. Append sd_first <- sd(first) and sd_second <- sd(second), then display each named result on its own line. Compare the SDs in your answer.

study <- read.csv("data/study.csv")
first <- study$reversal_mV[study$group == "Baseline"]
second <- study$reversal_mV[study$group == "Acquisition"]
mean(first)
median(first)

6. How many bars tell the story? — 15 minutes

A histogram groups measurements into intervals called bins. Bar height counts observations inside each interval. A few broad bins can hide structure; many narrow bins can make a small sample look full of gaps. Neither setting adds information. The marks below the bars show where the actual observations lie. Both groups below use the same bins and axes.

Try to make the data look as smooth as possible, then as irregular as possible. Ask your partner which biological conclusions survive both views. This is a challenge to the display, not an invitation to select whichever plot supports your preferred story.

Make a histogram you can rerun

hist() draws a histogram. breaks = 5 requests roughly five bins; base R chooses convenient boundaries, so the actual count can differ. The slider above uses exact boundaries. main sets the title and xlab labels the horizontal axis. Keep the Baseline example and append second_hist <- hist(second, breaks = 5, main = "Acquisition", xlab = "Mean GABA reversal potential (mV)").

study <- read.csv("data/study.csv")
first <- study$reversal_mV[study$group == "Baseline"]
second <- study$reversal_mV[study$group == "Acquisition"]
hist(first, breaks=5, main="Baseline", xlab="Mean GABA reversal potential (mV)")

7. Show the animals behind the average — 10 minutes

factor() below fixes the display order so colours and group positions stay consistent across figures. It does not change any measurements.

A boxplot puts the middle half of the observations inside a box. The line is the median. Whiskers extend to observations within 1.5 box lengths of the box; more distant observations are conventionally drawn separately. These points deserve investigation, not automatic deletion. With small samples, always look at the actual observations as well.

In R’s plot formula reversal_mV ~ group, read ~ as “shown by group”. data = study tells R where those column names live. stripchart() adds individual observations. Jitter moves points sideways slightly to reveal overlap; it never changes their measured height. set.seed(7) makes that sideways movement repeatable.

Can the mean-only chart tell the whole story?

Run the supplied bar chart, which shows only two means. Append the following worked template to add a boxplot with all animals. Run, inspect and submit. You do not need to invent the plotting syntax.

study$group <- factor(study$group, levels=c("Baseline","Acquisition"))
comparison <- boxplot(reversal_mV ~ group, data=study, outline=FALSE,
  ylab="Mean GABA reversal potential (mV)", xlab="Group", col=c("lightblue","peachpuff"))
set.seed(7)
stripchart(reversal_mV ~ group, data=study, vertical=TRUE, method="jitter",
  jitter=0.1, add=TRUE, pch=16)
study <- read.csv("data/study.csv")
first <- study$reversal_mV[study$group == "Baseline"]
second <- study$reversal_mV[study$group == "Acquisition"]
barplot(c(mean(first),mean(second)),names.arg=c("Baseline","Acquisition"),
  ylab="Mean: Mean GABA reversal potential (mV)",main="Only the means")

A smooth violin from a small sample?

A violin’s width estimates where measurements are more concentrated. The dots are observed; the smooth outline is calculated. Each violin here has equal maximum width and stops at its observed range; width does not encode sample size or a confidence interval. The short line is the median. Change the smoothing: can you make a bump vanish without changing a single animal?

Change smoothing in the live tutorial and explain what is estimated.

8. Two measurements from the same animal — 10 minutes

A scatterplot gives each animal one point. Its horizontal and vertical positions show two different measurements from that animal. A rising pattern suggests positive association; a falling pattern suggests negative association. First inspect a single group, so a difference between groups is not mistaken for a relationship within a group.
